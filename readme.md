# ⚡ Enterprise AI Data Pipeline & Cleansing Engine

A production-ready, cloud-deployed enterprise data cleansing and semantic normalization platform designed to ingest messy cross-functional datasets and output structured, institutional-grade Excel reports.

---

## 🚀 Live Demo
Access the live production application here: [View Live App](https://your-streamlit-app-url.streamlit.app)

---

## 🛠️ Tech Stack & Architecture
* **Backend:** FastAPI, Python, Pandas, Uvicorn, Google Gemini API
* **Frontend:** Streamlit Cloud (High-Contrast Modern Dark UI)
* **Hosting & Deployment:** Render Cloud (API Backend) & Streamlit Community Cloud (UI)
* **Data Handling:** OpenPyXL, Requests, Asynchronous Batch Chunking

---

## 🌟 Key Features
1. **Multi-Domain Data Support:** Seamlessly parses unstructured files from Finance (Ledgers), Sales (CRM metrics), HR (Headcount logs), and IT (Server event telemetry).
2. **Massive Scale Batch Processing:** Utilizes an intelligent 1,000-row chunking pipeline to handle heavy datasets (millions of rows) safely without triggering memory overflow or API gateway timeouts.
3. **Instant Excel Structuring & Download:** Converts unformatted text or irregular columns into a clean, standardized schema with a single click.
4. **Enterprise-Grade UI:** High-visibility dark-mode layout featuring real-time telemetry metrics (dataset row count, column dimensions, and memory footprint).
